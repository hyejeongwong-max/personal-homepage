# hyejeong 个人主页

> AI 产品经理 × 交互设计师 × 开发者 · 个人作品集主页（V0.1.0 低保真预览版）

单页式个人主页，排版参考 oiloil.org 的布局方式（编号区块、锚点导航、条目式列表），视觉为低保真线框示意。

## 版本

- 当前版本：V0.1.0（低保真预览版）
- 存档分支：`V.0.1.0`

## 页面结构

- 顶部导航（锚点）：首页 / 产品 / 技能 / 文章 / 关于我 / 联系
- Hero：一句话定位 + 角色标签
- #01 产品：编号条目列表（占位，待替换真实项目）
- 技能：四组分类标签
- 文章：日期 + 标题 + 摘要列表（占位）
- 关于我：标签 + 编号经历条目
- #02 联系 / Elsewhere：6 平台入口（GitHub / X / Email / 哔哩哔哩 / 小红书 / 抖音）

## 技术栈

- 纯 HTML + CSS，单文件自包含
- 响应式：桌面 / 移动端适配
